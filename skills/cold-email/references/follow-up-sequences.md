# 跟进序列

55% 的回复来自跟进邮件，而不是第一封初始邮件。但现实是，48% 的销售人员连一次跟进都不会做。

## 数量：总共 3–5 封邮件

- 单封邮件的最高回复率：**8.4%**（Belkins）。
- 4–7 封邮件的 campaign，回复率可达 **27%**，而 1–3 封只有 9%（Woodpecker，2000 万封邮件样本）。
- 到第 4 次跟进时，回复率会下降 **55%**，垃圾邮件投诉会**翻三倍**。
- 合理结论是：更长的序列能覆盖不同时间窗口，但最好把跟进控制在 4 次以内（总共 5 封）。每一封都必须带来真正新的价值。

## 最优节奏

每一次触达之间的间隔应逐步拉长：

| 触达 | 天数 | 说明 |
| ------------- | ----- | ---------------------------------------------- |
| 初始邮件 | 0 | 投入最高程度的个性化 |
| 跟进 1 | 3 | 等 3 天能让回复率提高最多 31% |
| 跟进 2 | 7–8 | 换一个角度 |
| 跟进 3 | 14 | 给出新的价值材料 |
| 跟进 4 | 21–28 | breakup email |

**最佳日期：** 周二到周四（周四峰值为 6.87% 回复率）。  
**最佳时间：** 收件人当地时间上午 9–11 点，或下午 1–3 点。  
**避免：** 周一早晨（收件箱过载）和周五下午（对方已经切出工作状态）。

## 角度轮换

每一封跟进都必须是可以独立成立的，同时又在朝共同目标推进。永远不要只是写一句 “bump this up”。

| 邮件 | 角度 | 目的 |
| ----------- | ---------------------------------------------------------- | -------------------------- |
| 初始邮件 | 个性化切入 + 核心价值主张 + 低压 CTA | 引入问题 / 方案 |
| 跟进 1 | 不同角度、一个新价值点（数据、洞察、资源） | 展示更多收益 |
| 跟进 2 | 相似公司社会证明 / case study | 建立可信度 |
| 跟进 3 | 新洞察、行业趋势或相关资源 | 展示专业度 |
| 跟进 4 | Breakup，承认对方没回应，保留未来窗口 | 触发损失厌恶 |

每封邮件只增加 **一个新价值主张**（SalesBread）。这样自然会迫使你每次切换角度。

## Breakup 邮件

它利用的是损失厌恶心理，也就是你收回压力、同时通过“退出”制造稀缺感。Close.com 的数据表明，breakup email 对 cold prospect 的回复率能达到 **10–15%**。

**结构：**

1. 说明你已经联系过几次
2. 承认对方可能确实暂时没兴趣
3. 明确说这是你这轮最后一封邮件
4. 把门留着

**示例：**

> I haven't heard back, so I'll assume now isn't the right time. Before I close the loop: [1-sentence insight or resource]. If that changes things, feel free to reply. Otherwise, no hard feelings — good luck with [their goal].

**1-2-3 格式**（几乎把回复阻力降到最低）：

> Since I haven't heard back, I'll keep it simple. Reply with a number:
>
> 1 — Interested, let's talk
> 2 — Not now, check back in 3 months
> 3 — Not interested, please stop

**关键规则：** 如果你发了 breakup email，就要言而有信。不要再主动联系对方。

## 会严重拉低回复率的表达

- `"I never heard back"` → 预约率下降 **12%**（Gong）
- `"Just checking in"` → 没有任何价值，只暴露偷懒
- `"Bumping this to the top of your inbox"` → 过于自以为是
- `"Did you see my last email?"` → 带有道德绑架感
- `"Following up on my previous message"` → 过于泛泛，没有新增信息

## 按职级调整 CTA

**高管 / 创始人：** 用超低阻力、以好奇心驱动的 CTA，例如 `"Curious?"` 或 `"Worth 2 min?"`

**中层管理者：** 可以更具体一些，例如 `"Want me to walk through how [Company] saved 15 hours/week?"`

组织层级越高，你能要求的动作阻力就越低。
